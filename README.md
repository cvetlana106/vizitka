# Визитка — Кудряшова Алия

Персональная онлайн-визитка: торговля онлайн и офлайн, работа с маркетплейсами **Ozon** и **Wildberries**.

## Что есть на странице

- Имя и описание деятельности
- Кнопка «Написать мне» — открывает Telegram
- Копирование ника в один клик
- Кнопка «Поделиться» (на телефоне открывает стандартное меню «Поделиться»)
- Анимации и адаптивная вёрстка для телефона и компьютера

## Как устроено

Вся визитка — один файл [`index.html`](index.html) без внешних зависимостей.
Чтобы посмотреть локально, достаточно открыть его в браузере.

Сайт публикуется через GitHub Pages.
